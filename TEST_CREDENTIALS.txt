────────────────────────────────────────────────────────────────────────────────
  SECTION 9 — QUICK SETUP ORDER
────────────────────────────────────────────────────────────────────────────────

  Recommended order to populate the system end-to-end:

  1. Run seed:          npx prisma db seed
  2. Log in as:         admin_route (SchoolAdmin)
  3. Create classes:    Academics → Add New Class (use Section 2 data)
  4. Add teachers:      Teachers → Add Teacher (use Section 3 data)
  5. Assign teachers:   Academics → Teacher Assignments (link teachers to classes)
  6. Admit students:    Students → New Admission (use Section 4 data)
  7. Add staff:         Staff → Add Staff (use Section 5 data)
  8. Add income:        Finance → Income → Add (use Section 6 data)
  9. Add expenses:      Finance → Expenses → Add (use Section 6 data)
  10. Mark attendance:  Attendance → Mark Attendance (pick any class)
  11. Check reports:    Reports → Fee Collection / Income-Expense
  12. Create users:     Users & Roles → Create User (use Section 7 for teachers)
  13. Test teacher login: log in as usman.akhtar, mark attendance, post homework
